Anatomy of a node

one card, read closely

Every node is the same small promise: inputs on the left, the work in the middle, an output on the right. Learn this card and you’ve read them all.

Image Video 3D Audio Image flux-2-proflux-2-progpt-image-2ideogram-v3recraft-v4 prompt image image

01The header names the verb. Image, Video, 3D, Audio: one card, one job, stated in a word.

02Ports are coloured by cargo. Purple is text, teal is image, apricot is video, blue is 3D. This card takes a prompt and a reference picture, and you can read that from across the room.

03The well is the work. Results land full-bleed in the card itself. No preview button, no popup: the picture is the interface.

04The model is a visible choice. flux-2-pro sits on the face of the card, never buried in settings, printed where you can question it.

05Run lives on the node. Press play on the card, not in a global toolbar. Progress paints under the work, and a finished node earns its check.

06The output hands it on. Whatever this card makes becomes the next one’s input the moment a wire leaves this port. Small promises, chained into a pipeline.

03then teach the machines

Chapter 3: The AI guide

a design system machines can read

A design system starts to drift the moment a machine starts drawing. So we wrote it down as a generation contract: a skill an AI agent loads before it touches a screen. Reuse before inventing, one truth source, and a list of things it must never do.
